# WFRP4e: Oś czasu zajęć (`wfrp4e-downtime-timeline`)

Moduł do **Foundry VTT** dla systemu **Warhammer Fantasy Roleplay 4e**: oś czasu spięta z Simple Calendar
do planowania i rozliczania powtarzalnych czynności postaci (downtime) — testów, testów wydłużonych i zarobkowania.

## Instalacja

W Foundry: **Setup → Moduły dodatkowe → Zainstaluj moduł**, w polu *Adres URL manifestu* wklej:

```
https://github.com/Ilinar/wfrp4e-downtime-timeline/releases/latest/download/module.json
```

Nowe wersje pojawiają się potem przy **Sprawdź aktualizacje** na liście modułów.

**Zalecany:** [Simple Calendar Reborn](https://github.com/Fireblight-Studios/foundryvtt-simple-calendar)
(Fireblight Studios, id `foundryvtt-simple-calendar-reborn`) — daje kalendarz imperialny i tydzień WFRP.
Bez niego oś działa na rdzeniowym czasie świata.
